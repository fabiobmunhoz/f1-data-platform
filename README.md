# F1 Data Platform

End-to-end data engineering project using Formula 1 data.

## Objective

Build a complete data platform to ingest, process, transform, orchestrate and analyze Formula 1 data.

## Initial Tech Stack

- Python
- Pandas
- Requests
- Git / GitHub

## Planned Stack

- PySpark
- Apache Airflow
- Docker
- Azure
- Databricks
- SQL

## Project Structure

- `src/ingestion` - Data ingestion
- `src/transformations` - Data transformations
- `src/quality` - Data quality checks
- `data/bronze` - Raw data
- `data/silver` - Cleaned and standardized data
- `data/gold` - Analytics-ready data
- `dags` - Airflow DAGs
- `tests` - Automated tests
- `notebooks` - Exploration and development
- `docs` - Project documentation

## Current Status

Initial environment configured and first Formula 1 API integration completed.
